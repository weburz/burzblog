# Security policy

## Supported versions

Security fixes are released for the latest 2.x version. Please upgrade before
reporting an issue you found in an older version.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately through
GitHub: open the [Security tab of weburz/burzblog](https://github.com/weburz/burzblog/security)
and choose **Report a vulnerability** to create a private security advisory.

Include the version, what you did, what you expected and what happened, and a
proof of concept if you have one. Do not include real credentials or content.

You can expect an acknowledgement within a few days. We will keep you updated
while we work on a fix and credit you in the advisory unless you prefer not to
be named.

## Scope

[docs/security.md](docs/security.md) describes the security model: what
BurzBlog protects and the assumptions it makes about the host.
